# /api [resource|flow]

Require typed input/output, Zod validation, authentication, authorization,
organization/project scope, idempotency, rate limits, CSRF where applicable,
audit behavior, safe errors, and contract tests. Never expose secrets or
unnecessary PII. Fixes require a focused approved phase and independent review.
