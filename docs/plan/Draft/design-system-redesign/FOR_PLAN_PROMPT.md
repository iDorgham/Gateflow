## Initiative Overview

**Slug:** design-system-redesign  
**Vision:** Redesign and expand the GateFlow design system into a premium, serious, enterprise-grade PropTech platform (ADS-inspired).

## Key Goals

- **Token-First Excellence**: Zero hardcoded values; 100% `--ds-*` semantic coverage.
- **DNA Overhaul**: Implement "Satin-Charcoal" dark mode (OKLCH hierarchy) with Kimchi, Cobalt, and Emerald accent profiles.
- **Documentation**: 12+ Specialized pages in `apps/design-system` covering Foundations and Patterns.
- **Cross-App Parity**: Consistency across Marketing, Dashboards, Portal, and Mobile (Scanner + Resident).
- **RTL/Accessibility**: Cairo/Inter fonts, CSS logical properties, and WCAG AA compliance.

## Foundation Specifications

- **Colors**: Satin-Charcoal (8%, 11%, 14%, 22% L tiers). OKLCH-based.
- **Typography**: Fluid `clamp()` scale. Inter & Cairo.
- **Iconography**: 1.5px stroke Lucide + Sentinel Glow.
- **Spacing/Grid**: 8pt grid with logical standard margins/paddings.
- **Layering**: Semantic Z-Index stack (Toast 1000 > Base 1).
- **Motion**: Cine-Professional easings + stiff-spring 50ms staggering.
