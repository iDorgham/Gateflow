## 🏹 Primary Tasks

1.  **Colors & Accent Profiles (`/colors`)**:
    - Create a page displaying the "Satin-Charcoal" neutral ramps.
    - Implement a "Profile Switcher" interactive lab to toggle between Kimchi, Cobalt, and Emerald profiles (testing the `[data-accent-profile]` mechanism).

2.  **Typography & Scale (`/typography`)**:
    - Create a typography specimen page demonstrating Inter and Cairo fonts.

3.  **Iconography & Micro-interactions (`/iconography`)**:
    - Build an icon gallery using Lucide (1.5px stroke weight).
    - Implement a "Sentinel Glow" lab where icons pulse with brand theme glows.

4.  **Spacing & Grid Lab (`/spacing`)**:
    - Visualize the 8pt grid system.
    - Show semantic utilities (GAP, INSET) and logical layout examples (Start/End).

5.  **Layering & Depth Visualizer (`/layering`)**:
    - Create a 3D-style visualization of the Z-Index stack (Z-0 to Z-1000).
    - Map specific Elevation FX (Shadow, Glow, Blur) to each level.

6.  **Motion Playground (`/motion`)**:
    - Create an easing visualizer for the new "Cine-Serious" durations and curves.
    - Include examples of "Staggered Entrances" for high-density components.
