## 1. Overview & Architectural Role

`client-dashboard` is GateFlow's primary operational command center for enterprise compound managers, property operators, and security supervisors. It manages the full entity hierarchy: organizations, compound projects, residential/commercial units, gate locations, staff guard assignments, visitor access passes, and real-time security scan events.

### Core Architecture

- **Framework:** Next.js 16 App Router with React Server Components (RSC) and server actions.
- **Data Access:** Request-scoped Prisma client (`packages/db`) enforcing `AsyncLocalStorage` tenant context on every query.
- **State & UI:** Antigravity Design System (ADS) tokens, Tailwind CSS v4, Lucide icons, `@gateflow/ui` components.
- **Authentication & Sessions:** NextAuth.js JWT session with cross-subdomain cookie domain (`AUTH_COOKIE_DOMAIN=.gateflow.site`), Argon2id password hashing, and single-session revocation.

## 3. Pros and Cons Analysis

### Pros (Strengths)

1. **Bulletproof Tenant Isolation:** Uses request-local `AsyncLocalStorage` guards preventing cross-tenant data leakage.
2. **Cryptographic QR Integrity:** HMAC-SHA256 signed payloads with single-use nonce consumption and DB ID synchronization.
3. **Cross-Subdomain SSO:** Seamless authentication handoff between `app.gateflow.site` and `portal.gateflow.site`.
4. **Rich Operational UI:** High-density tables, live analytics, CSV bulk export/import, and robust skeleton loaders.

### Cons (Weaknesses & Tech Debt)

1. **Route Bloat:** Over 30+ nested subroutes under `[locale]/dashboard/organizations/[orgId]/` that require ongoing bundle optimization.
2. **Local Helper Duplications:** Residual local `cn()` utilities in some sub-components instead of importing `@gateflow/ui/utils`.
3. **Vercel Hobby Deployment Quotas:** API deployment rate limits require careful build skipping via `ignoreCommand`.
