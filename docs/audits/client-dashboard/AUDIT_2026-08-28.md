## 1. Executive Summary & Application Scope

The GateFlow Client Dashboard (`app.gateflow.site`) is the core enterprise SaaS command console for property managers, community operators, and security supervisors. It encompasses:

1. **Perimeter Situational Awareness**: Live visual map rendering gate terminal occupancy, active guard shifts, and patrol progress.
2. **Cryptographic Access Control**: HMAC-SHA256 QR visitor pass studio with custom usage quotas and time boundaries.
3. **Guard Patrol Route Manager**: Interactive route sequencing, checkpoint ordering, and physical HMAC QR print generation.
4. **CRM & Resident Management**: High-density tables for Units, Residents, Contacts, and Vehicles with export rate limiting.
5. **GateAI Autonomous Operations**: Multi-part agentic assistant delegating maintenance tickets, generating shift summaries, and analyzing scan trends.

## 2. Component Architecture & Surface Inventory

### 2.1 Perimeter Operations & Patrol Telemetry (`src/components/dashboard/gates/`)

- **`GuardShiftVisualMap.tsx`**:
  - Live interactive map displaying compound gates, terminal lane states, and guard occupancy.
  - Renders live polyline paths tracking guard patrol checkpoint progression in real time.
- **`PatrolRouteManager.tsx` & `PatrolRouteModal.tsx`**:
  - CRUD interface for defining perimeter patrol loops, checkpoint ordering, and expected schedule windows.
  - Generates downloadable/printable high-resolution cryptographic QR tokens for physical placement.
- **`PatrolComplianceSummary.tsx`**:
  - Aggregates on-time vs delayed checkpoints, completed patrol runs, and active supervisor alerts.
- **`ShiftHandoverDrawer.tsx`**:
  - Enables guards and supervisors to close active shifts, log handover notes, and transfer duty to incoming relief guards.

### 2.2 CRM & High-Density Operational Tables (`src/components/crm/`, `src/components/qrcodes/`)

- **`ContactTable.tsx` & `UnitTable.tsx`**:
  - High-density data grids supporting column sorting, multi-attribute filtering, and custom user preference saved views.
  - CSV export is rate-limited and automatically commits a signed `AuditLog` entry for compliance.
- **`QRCodeTable.tsx` & `QRCodeCreateWizard.tsx`**:
  - Multi-step pass generation wizard enforcing multi-tenancy rules and HMAC payload signing.

### 2.3 GateAI Autonomous Assistant (`src/components/ai/`, `src/lib/ai-v6/`)

- **Vercel AI SDK v6 Engine**: Multi-part UIMessage architecture with client-side interactive tool confirmation dialogs (`ToolLifecycleModal.tsx`).
- **Autonomous Dispatchers**: Automated maintenance work order escalation on recurring gate scan anomalies (`MaintenanceExecutor`).

## 3. Exhaustive API Route Inventory (`src/app/api/`)

### 3.1 Patrol & Shift Management

- `POST /api/patrols/routes`: Multi-tenant patrol route creation and checkpoint sequencing.
- `POST /api/patrols/scan`: Guard checkpoint verification with HMAC validation.
- `GET /api/patrols/live`: Real-time patrol compliance aggregation.
- `POST /api/scanner/shift/start`: Starts/resumes guard duty shift session.
- `POST /api/scanner/shift/end`: Closes active shift session and calculates summary scan metrics.
- `GET /api/scanner/shift/active`: Returns live shift session for authenticated guard.
- `GET /api/scanner/shift/live`: Live multi-terminal telemetry feed.

### 3.2 Access & Scans

- `POST /api/scans` & `POST /api/scans/bulk`: Single scan validation and bulk offline queue drainage.
- `GET /api/scans/stream`: Server-Sent Events (SSE) live scan event feed.
- `POST /api/qrcodes` / `GET /api/qrcodes`: Cryptographic QR pass generation and querying.

### 3.3 Security & Multi-Tenancy

- `GET /api/security/audit-export`: Cryptographically chained audit log export.
- `POST /api/auth/step-up`: Elevated privilege step-up authentication challenge.
- `GET /api/api-keys` & `GET /api/webhooks`: Developer API keys and webhook event dispatchers.
