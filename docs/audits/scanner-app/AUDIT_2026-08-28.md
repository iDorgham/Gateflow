## 1. Executive Summary & Application Scope

The GateFlow Scanner App is the frontline operational surface used by security guards, terminal operators, and patrol officers at compound access gates and perimeter checkpoints. It is engineered for:

1. **Sub-second QR pass verification** ($<120\text{ms}$ cold/hot verification latency).
2. **Offline-first continuity** with encrypted local storage queue and automatic cloud sync.
3. **Fail-closed biometric & PIN security** preventing unauthorized or unattended terminal access.
4. **Shift-gated scanning accountability** ensuring all scans occur during active, assigned guard duties.
5. **Perimeter guard patrol route tracking** with HMAC-signed QR checkpoint verification.

## 2. Component Architecture & Surface Inventory

### 2.1 First-Mile Onboarding Navigator (`src/navigators/onboarding-navigator.tsx`)

- **Step 1: Vision & Policy (`src/screens/onboarding/vision-screen.tsx`)**:
  - Outlines zero-trust gate requirements, zero-leakage visitor privacy, and duty shift obligations.
- **Step 2: Hardware Permissions (`src/screens/onboarding/permissions-screen.tsx`)**:
  - Requests Camera (`Camera.requestCameraPermissionsAsync()`) and Haptic feedback.
  - Features deep-link recovery: if permissions are permanently denied, displays `Linking.openSettings()` button to transition the user into OS settings without stalling.
- **Step 3: Security & PIN Vault Setup (`src/screens/onboarding/security-setup-screen.tsx`)**:
  - Probes device biometrics via `expo-local-authentication`.
  - Prompts for mandatory 6-digit Master PIN via custom `PinKeypad` and animated `PinDots`.
  - Salts and hashes PIN with SHA-256 before writing to `expo-secure-store`.
- **Step 4: Duty Gate Activation (`src/screens/onboarding/gate-activation-screen.tsx`)**:
  - Queries available gate terminals in the tenant organization and commits initial terminal assignment.

### 2.2 Command Center Home Dashboard (`src/screens/main/home-screen.tsx`)

- **Layout Standards**: 100% adherence to 8pt spatial grid and `@gateflow/ui/tokens` (`nativeTokens`).
- **Master Scan FAB (`src/components/home/master-scan-fab.tsx`)**:
  - 72x72px circular action button with `ScanLine` icon, `nativeTokens.colors.primary` fill, and `brandGlow` elevation shadow.
  - Launches camera scanner in $<1\text{s}$.
- **Live Duty Telemetry Widget (`src/components/home/shift-info-widget.tsx`)**:
  - Isolated internal 1-second interval timer updating elapsed duty duration without causing full-screen re-renders.
  - Semantic status pill with live indicator dot (**On duty** vs **Off duty**).
- **High-Density Stats Grid**:
  - Displays "Scans today" counter, "Pending sync" offline queue count, and network connectivity state.

### 2.3 Security, Inactivity & Unlock Shell

- **Biometric Inactivity Guard (`src/components/security/biometric-guard.tsx`)**:
  - Wraps the application shell and tracks touch interactions using `PanResponder` with `onStartShouldSetPanResponderCapture: () => false` (transparent observation).
  - Enforces 5-minute inactivity timeout (`DEFAULT_INACTIVITY_TIMEOUT_MS = 300,000ms`).
  - Calls `onLock` on inactivity or returning from 5+ minutes of backgrounding.
- **Device Unlock Screen (`src/screens/security/device-unlock-screen.tsx`)**:
  - Prompts for biometric unlock (FaceID/Fingerprint) with fallback to Master PIN.
  - Enforces exponential lockout throttling via `LockoutManager` (3 failed attempts $\rightarrow$ 60s lockout).

## 3. Cryptographic & Security Invariants

| Security Boundary                | Implementation                                | Invariant Guarantee                                                                                                             |
| :------------------------------- | :-------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------ |
| **Biometric Fail-Closed**        | `biometrics.ts`, `secure-pin.ts`              | If hardware biometrics are un-enrolled, unavailable, or bypassed, the app strictly requires 6-digit PIN before granting access. |
| **Shift-Gated Scanning**         | `shift-session.ts`, `camera-scanner-view.tsx` | Camera barcode scan callbacks are hard-blocked when `canScanWithShift(session, gateId) === false`.                              |
| **Tombstone Session Protection** | `shift-session.ts` (`SHIFT_TOMBSTONE_KEY`)    | When a shift ends or is marked pending, an immutable tombstone is recorded in SecureStore preventing revival from stale memory. |
| **Anti-Replay Nonce Quarantine** | `nonce-quarantine.ts`, `qr-verify.ts`         | QR pass nonces are tracked in sliding memory window to reject replayed tokens.                                                  |
| **Offline Queue Encryption**     | `offline-queue.ts`                            | All cached scan logs are encrypted at rest with AES-256 + PBKDF2 derived keys.                                                  |
| **Secret Verification**          | `qr-secret.ts`                                | Scans fail-closed if `EXPO_PUBLIC_QR_SECRET` is missing or invalid.                                                             |
