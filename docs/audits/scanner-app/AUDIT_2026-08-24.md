## 1. Overview & Architectural Role

`scanner-app` is GateFlow's dedicated mobile security terminal for compound gate guards and access controllers. It turns standard iOS and Android smartphones into hardened, sub-second QR code scanners that operate reliably in full offline environments, power outages, or intermittent compound cellular coverage.

### Core Architecture

- **Framework:** Expo SDK 57 (React Native 0.76+) with native camera hooks (`expo-camera`) and SecureStore hardware key isolation.
- **Offline Storage & Encryption:** Encrypted scan queue using **AES-CBC v3** in AsyncStorage; drains automatically via `POST /scans/bulk` upon reconnection.
- **Security & Session Guard:** `BiometricGuard` non-intrusive pan-gesture observer with 5-minute auto-lock; preserves active guard duty shifts across UI locks.
- **Fail-Closed Verification:** Client-side HMAC-SHA256 signature verification + backend database validation against active gate assignments.

## 3. Pros and Cons Analysis

### Pros (Strengths)

1. **True Offline Capability:** Scans can be validated against offline cryptographic rules and stored in AES-CBC encrypted queues when connectivity drops.
2. **Deterministic Anti-Replay Defense:** Prevents pass reuse or clone attacks through timestamp windowing and nonce consumption.
3. **Zero Heavy Native Binary Friction:** Uses core React Native `Animated` (`useNativeDriver: true`) instead of unstable native reanimated builds on Expo dev clients.
4. **Shift & Gate Accountability:** Guards cannot scan without an active, verified shift assigned to a specific compound gate.

### Cons (Weaknesses & Tech Debt)

1. **Monolithic `App.tsx` (2,100+ lines):** Combines login, onboarding wizard, camera frames, BiometricGuard, and tab navigation in a single file.
2. **Missing `@gate-access/i18n` Localization Strings:** Layout is RTL-ready, but strings are currently English hardcoded; Arabic translation catalog is pending wiring.
3. **Headless Hermes Compiler Export Glitch:** Headless `expo export --bytecode` can hit a dependency resolution error on `hermes-compiler`.
