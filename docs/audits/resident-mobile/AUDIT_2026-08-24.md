## 1. Overview & Architectural Role

`resident-mobile` is GateFlow's native mobile client (iOS and Android) for compound residents. It provides instant 1-tap pass generation, push notifications when visitors are scanned at the gate, biometric app unlock (Face ID / Fingerprint), and offline pass vaulting.

### Core Architecture

- **Framework:** Expo SDK 57 / React Native with Expo Router.
- **Design Tokens:** Shared `@gateflow/ui` native token system (`nativeTokensNewEra`) ensuring visual parity with `resident-portal`.
- **Security:** Hardware-backed biometric authentication (`expo-local-authentication`) and SecureStore credential isolation.

---

## 2. Verification & Status

- **Feature Completeness:** 1-Tap pass generation, visitor logs, and unit profile features implemented.
- **Token Compliance:** Aligned with Antigravity Design System 8pt grid tokens and resolved hex color values for scannable printable QR exports.

---

## 3. Pros and Cons Analysis

### Pros (Strengths)

1. **App Store Readiness:** Packaged for native distribution via Apple App Store and Google Play.
2. **Native Push Notifications:** Real-time push alerts to residents when their guest is scanned at the perimeter gate.
3. **Biometric Speed:** Fast-unlock via Face ID / Touch ID.

### Cons (Weaknesses & Tech Debt)

1. **Parallel Maintenance with PWA:** Features in `resident-portal` must be kept in sync with `resident-mobile`.
2. **Xcode 26.4+ Requirement:** Expo SDK 57 iOS native builds require Swift 6.3 / Xcode 26.4+.
