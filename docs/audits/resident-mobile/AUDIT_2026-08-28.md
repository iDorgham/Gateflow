## 1. Executive Summary & Application Scope

The GateFlow Resident Mobile App is the native smartphone application for compound residents. It provides:

1. **Native Smartphone Digital Key**: Instant cryptographic pass generation with biometric authorization (FaceID/TouchID).
2. **Visitor Invitation & OS Share Sheet**: Seamless contact book access and multi-channel pass sharing (WhatsApp, SMS, Email).
3. **Real-Time Arrival Push Feeds**: Push notifications delivered instantly when a visitor's QR code is validated at a gate terminal.
4. **GPS Guest Navigation**: Optional route directions guiding visitors from the gate barrier directly to the resident's unit.

---

## 2. Key Modules & Technical Capabilities

- **`OneTapPassWidget`**: Fast pass generation using device biometrics and tenant-scoped HMAC signing.
- **`ArrivalPushListener`**: Listens for WebSocket/Push arrival events and displays animated alert cards.
- **`AccessRuleSelector`**: Configures one-time, multi-day, or recurring delivery passes with quota enforcement.
- **`Bilingual Cairo Typography`**: High-contrast Arabic RTL and English interface rendering.
