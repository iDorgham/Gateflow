## 1. Executive Summary & Token Architecture

GateFlow enforces a strict, unified design token architecture across all web and mobile surfaces:

- **Web Applications (`client-dashboard`, `admin-dashboard`, `marketing`, `resident-portal`)**: Styled using pure semantic CSS variables (`var(--ds-background-default)`, `var(--ds-text-primary)`, `var(--ds-border-default)`).
- **Mobile Applications (`scanner-app`, `resident-mobile`)**: Styled using resolved `nativeTokens` from `@gateflow/ui/tokens` with strict dark-mode contrast ratios.
- **Zero Raw Hex Invariant**: No ad-hoc, un-themed hex codes are allowed in certified UI surfaces.

---

## 2. Spatial Grid & Component Primitives

- **8pt Spatial Grid**: All margins, paddings, gaps, and heights follow strict 8pt multiples (`space-050: 4px`, `space-100: 8px`, `space-150: 12px`, `space-200: 16px`, `space-300: 24px`, `space-400: 32px`).
- **Shared Primitives in `packages/ui/src/`**:
  - `Button`, `Badge`, `Card`, `Modal`, `Input`, `Select`, `DropdownMenu`, `Tabs`.
  - `BrandGlow` elevation shadows and micro-interaction animations.
  - Bidirectional RTL mirroring helpers for Arabic locales.
