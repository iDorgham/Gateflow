## 1. Overview & Architectural Role

GateFlow Design System (ADS / Antigravity Design System) provides the monorepo's shared visual foundation, token architecture, and accessible UI component suite. It enforces strict consistency across all web dashboards, marketing pages, and mobile applications.

### Core Architecture

- **Tokens (`@gateflow/tokens`):** OKLCH color palettes, 8pt spacing grid, semantic elevation, dynamic typography scale.
- **Theme (`@gateflow/theme`):** Dark mode engine (`data-color-mode`), CSS variable injection, system preference detection.
- **UI Kit (`@gateflow/ui`):** Composable React 19 / Next.js 16 UI primitives with zero ad-hoc styling.
- **AI UI Kit (`@gateflow/ai`):** Streaming chat bubbles, ToolCards, parameter inspectors, and interactive metric charts for GateAI.

## 3. Pros and Cons Analysis

### Pros (Strengths)

1. **High Visual Density & Polish:** Tailored for operational software with calm, readable contrast and minimal visual noise.
2. **Unified Web + Mobile Design Tokens:** Single source of truth for color and spacing across Next.js and React Native.
3. **Dedicated AI Component Suite:** First-class primitives for agentic chat and tool execution interfaces.

### Cons (Weaknesses & Tech Debt)

1. **`apps/design-system` vs `packages/ui` Duplication:** Core development happens in `packages/ui`; `apps/design-system` serves mainly as documentation and gallery.
