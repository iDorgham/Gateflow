## 1. Executive Summary & Application Scope

The GateFlow Resident Portal (`portal.gateflow.site`) is the web and Progressive Web App (PWA) client for residents. It delivers:

1. **One-Tap Visitor Pass Studio**: Fast generation of cryptographic QR passes with customizable access windows.
2. **Open QR Delivery Passes**: Specialized passes for food and package deliveries with multi-scan constraints.
3. **PWA Offline Resilience**: Network-first Service Worker v2 preventing `ERR_FAILED` caching errors and enabling offline pass viewing.
4. **Instant WhatsApp / Native Sharing**: Web Share API integration for zero-friction invitation dispatch.
5. **Household & Access Logs**: Real-time log of who entered using the resident's passes and unit member management.

## 2. Route Tree & Component Architecture

### 2.1 Route Structure (`src/app/[locale]/`)

- `/(portal)/visitors`: Active visitor passes with search and status filters.
- `/(portal)/visitors/new`: Multi-step guest invitation builder with time constraints.
- `/(portal)/open-qr/new`: Delivery and recurring pass creator.
- `/(portal)/history`: Chronological visitor access log grouped by date.
- `/(portal)/maintenance`: Resident work-order submission interface.
- `/(portal)/profile`: Resident contact info and notification preferences.

### 2.2 Core Components & PWA Layer

- **`portal-shell.tsx` & `bottom-nav.tsx`**: Mobile-first responsive layout with bottom navigation for touch devices.
- **`visitor-form.tsx` & `visitor-qr-card.tsx`**: QR render with Web Share trigger and download SVG/PNG options.
- **`pwa-bootstrap.tsx` & Service Worker v2**: Network-first caching strategy with offline pass storage fallback.

---

## 3. Security & Multi-Tenancy Invariants

- **Unit Ownership Scoping**: Residents can ONLY create passes for units they own or are actively linked to (`ResidentUnit` mapping).
- **HMAC QR Signing**: Passes are signed with the tenant organization's secret key.
- **Cross-Subdomain SSO**: Shares `.gateflow.site` session cookie with `app.gateflow.site`.
