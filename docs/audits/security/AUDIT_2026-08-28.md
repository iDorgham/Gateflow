## 1. Executive Summary & Security Posture

GateFlow employs a comprehensive defense-in-depth security model engineered specifically for physical perimeter control, cloud SaaS tenancy, and mobile field hardware.

### Key Security Pillars:

1. **Zero-Trust Multi-Tenancy**: Strict `organizationId` scoping enforced at middleware, route handlers, and database query layers.
2. **Cryptographic QR Protocol**: HMAC-SHA256 signature verification with deterministic database `qrId` binding and sliding nonce quarantine.
3. **Field-Level PII Encryption**: Sensitive resident and visitor attributes (National ID, phone number, vehicle plate) encrypted at rest via AES-256-GCM.
4. **Tamper-Evident Audit Ledger**: Chained `AuditLog` records linking each mutation to the previous hash (`prevHash`).
5. **Fail-Closed Biometrics & Inactivity Lock**: Biometric hardware failure defaults to mandatory 6-digit PIN with anti-brute-force rate limiting (60s lockout after 3 failed attempts) and 5-minute inactivity lock.

## 2. Cryptographic Protocol Specifications

### 2.1 QR Pass Signature

$$\text{Signature} = \text{HMAC-SHA256}(\text{Secret}, \text{qrId} \parallel \text{orgId} \parallel \text{validFrom} \parallel \text{validUntil} \parallel \text{nonce})$$

- Payload format: `gf:v1:<base64-payload>.<base64-signature>`
- Hard failure modes: Expired timestamp, mismatched `organizationId`, previously consumed nonce, invalid HMAC signature.

### 2.2 Physical Barrier Relay Frame

Binary packet protocol with CCITT-CRC16 checksum verification:
$$[\text{0xAA}, \text{0x55}, \text{Cmd: 0x01}, \text{GateId: 2B}, \text{Duration: 2B}, \text{CRC16: 2B}, \text{0xEE}]$$
