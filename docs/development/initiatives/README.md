# GateFlow — initiatives (`IDEA_<slug>.md`)

`/idea` creates and maintains **`IDEA_<slug>.md`** files here. They are the **canonical “why”** for an initiative before and during phased planning.

## Conventions

- One file per initiative slug (e.g. `IDEA_core_security_v6.md`).
- Linked from `docs/plan/backlog/ALL_TASKS_BACKLOG.md` and from plan folders under `docs/plan/Draft|Ready|Active|Complete/<slug>/`.
