# `docs/development/plan-guides/`

Short, **plan-adjacent** how-tos that are not full methodology docs.

- **`docs/development/guidelines/`** — phased workflow, subagent hierarchy, AI rules (heavier reference).
- **`docs/development/plan-guides/`** (this folder) — quick procedural notes, checklists, and pointers.
- **`docs/guides/`** — repo-wide engineering guides (development, security, prompts, automation).

Add new files here when the audience is **planners and phase owners** rather than every contributor.
