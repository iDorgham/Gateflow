## Brain Structure

Together, **Context**, **Backlog**, **Execution**, **Guidelines**, and **Learning** form the shared planning and learning "brain" for GateFlow.

All tools (Cursor, Kiro, Antigravity, CLIs) must treat this tree as the single source of truth for ideas, plans, prompts, and cross-phase learnings.
