# Workspace Templates

Template sources used by this workspace:

- `.antigravity/templates/`
- `docs/plan/guidelines/TEMPLATE_*.md`

## Installation Requirement

When porting this workspace system to another project, create:

- plan prompt templates
- API route/test templates
- PR and commit templates
- definition-of-done templates
- subagent prompt libraries

See `../bootstrap/NEXT_PROJECT_PROMPT.md` for the bootstrap sequence.
