# Release Notes Template

Use this template for `CHANGELOG.md` under `## [Unreleased]`.

```md
## [Unreleased]

### Workspace

- **[Topic]** change summary.

### AI Tools

- **[Topic]** change summary.

### Apps

- **[App or Initiative]** change summary.
```

## Rules

- Keep every unreleased bullet in exactly one section: `Workspace`, `AI Tools`, or `Apps`.
- Do not add extra headings under `Unreleased`.
- Keep bullet format consistent: `- **[Tag]** description`.
