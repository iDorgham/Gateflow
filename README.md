## 🏛️ The Platform Ecosystem

GateFlow is a high-density, multi-tenant monorepo orchestrating six specialized applications. Each application is strictly decoupled, sharing a core design system, cryptographic standards, and real-time infrastructure.

### 🏢 Management & Administration Suites

Cloud-native interfaces for estate managers and platform operators.

- **[Client Dashboard](apps/client-dashboard)**: The operative nervous system. Real-time scan monitoring via SSE, Resident CRM, Unit/Gate management, and complex Marketing ROI analytics.
- **[Admin Dashboard](apps/admin-dashboard)**: Platform-governance hub. God-mode oversight for organization isolation, billing lifecycle, and global project key rotation.
- **[Marketing Engine](apps/marketing)**: High-speed SSR conversion funnels with UTM persistence and Physical-to-Digital pixel firing.

### 📲 Mobile & Resident Intelligence

Edge-optimized experiences for the 2026 mobile-first field environment.

- **[Resident Mobile](apps/resident-mobile)**: Native iOS/Android suit for zero-friction pass issuance. One-tap WhatsApp invites, instant arrival alerts, and high-fidelity pass history.
- **[Scanner App](apps/scanner-app)**: High-precision verification hub for guards. Offline-first HMAC validation, AES-256 local storage, and haptic feedback for <100ms verification.
- **[Resident Portal](apps/resident-portal)**: Web-based self-service for guest management, providing a unified experience across all hardware.

## 🛡️ Strategic Core Pillars

GateFlow is built on the principle that physical security and digital intelligence are one and the same.

### 1. Cryptographic Security (Zero-Trust)

Verification happens exclusively on the edge.

- **HMAC-SHA256 Signatures**: Every QR code contains a cryptographic proof of origin.
- **Local Vaulting**: Scanners cache verification logic and offline queues with military-grade encryption.
- **Tenant Isolation**: Database-level isolation via Prisma middleware ensures 100% data privacy across organizations.

### 2. Marketing ROI (Physical Attribution)

The first platform to close the loop between digital marketing spend and physical arrivals.

- **UTM Lifecycle Persistence**: Bind ad-clicks (Meta/Google/TikTok) directly to physical gate-scans.
- **Conversion APIs**: Automatic server-side event firing to advertising pixels upon successful physical check-in.
- **CRM Automation**: Real-time webhook syncs physical visit data to HubSpot and Salesforce.

### 3. High-Density Design (ADS-Native)

Strict adherence to the **Atlassian Design System (ADS)**.

- **Token-Led Theming**: Global typography, spacing, and color tokens for instant cross-platform consistency.
- **i18n & RTL Core**: Native Arabic/English support built into the layout engine, not patched on top.
- **Design for Performance**: Sub-second interactions even in high-density data tables and analytics dashboards.
